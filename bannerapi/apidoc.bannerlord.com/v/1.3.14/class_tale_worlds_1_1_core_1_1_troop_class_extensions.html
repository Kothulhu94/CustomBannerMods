FormationClass TaleWorlds.Core.TroopClassExtensions.DismountedClass ( this FormationClass troopClass)
static

Returns corresponding dismounted class (i.e. cavalry becomes infantry) of a troop class if it is a mounted class. returns the formationClass parameter without a change otherwise. General and Bodyguard classes can contain both dismounted and mounted troops so they wont change.
